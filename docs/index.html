How this is built

Parts of this work are AI-assisted.

Some code, docs and release tooling are written with the help of an AI coding assistant, under my direction and review. I say so because you should know how the software you install was made. It is not an official product of any AI company and is not endorsed by one. AI-assisted code can contain mistakes a human would not have made. Tests and manual checks reduce that risk, but cannot remove it.
